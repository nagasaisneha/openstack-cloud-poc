## Read-only preflight

Added [`inspect_cinder_readiness.py`](../../scripts/local-openstack/inspect_cinder_readiness.py) and [`test_cinder_readiness.py`](../../tests/test_cinder_readiness.py). The command is restricted to the existing Ubuntu 22.04 WSL POC and reuses its protected root-only credentials without printing or persisting them. It checks the Keystone `volumev3` endpoint, Cinder scheduler/volume service state, detailed scheduler pool capacity, project volume quotas, selected non-secret backend configuration fields, relevant systemd units, available memory, and acceptance-filesystem space. It saves a protected sanitized report and prints only allowlisted summary fields. It performs GET-only cloud calls and local read-only observations; it creates, attaches, detaches, snapshots, deletes and configures no storage resources or services.

Run after the retained cloud readiness pass:

```bash
sudo /usr/bin/python3 -B /home/sneha/projects/openstack-cloud-poc/scripts/local-openstack/inspect_cinder_readiness.py
```

Exit code 0 means the preflight found enough evidence for a separately scoped disposable-volume test; it does not constitute volume acceptance. Exit code 2 means the protected report contains a blocked readiness result. Return the `POC Cinder preflight: summary=...`, final status and report-path lines only. Do not copy `cinder.conf`, credential files, endpoint URLs, or raw logs. The preflight code and tests are implemented, but no live Cinder API/backend result is claimed until this command runs in the operator's WSL environment.

Verification before live run: `python3 -m unittest tests.test_cinder_readiness` — **5 tests passed**; script/test Python compilation and `git diff --check` passed.
