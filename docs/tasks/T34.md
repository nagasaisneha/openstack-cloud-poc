# T34 — Tenant compute, image, network, and access workflow

**Status (2026-10-27):** Locally verified subset in [T48](T48.md): two tenant
browser-created private networks/subnets, public-key imports, pinned image/tiny
flavor launches and interactive HTTPS/WSS consoles; provider foreign-resource
reads denied. Broader lifecycle/image/security-group cases below remain open.
No OS upgrade or restore rehearsal is a prerequisite for this work.

## Objective and scope

Expose the supported Nova/Glance/Neutron workflows to tenant users through Horizon. Include instance lifecycle/status, permitted images, key pairs, networks, security groups, quota feedback, and an approved browser-console or SSH access path.

**Dependencies:** T32–T33.
**Mapped requirements:** Tenant resource lifecycle, status/errors, image/network/key/security-group access, console/SSH, authorized resource listing.

## Acceptance criteria

- [ ] Each tenant lists, creates, inspects, starts/stops and deletes only its task-owned instances through the browser; provider status and job errors are truthful.
- [ ] Images are visible/usable only under the configured Keystone/Glance policy; project-private and shared image behavior is verified.
- [ ] Networks/security groups/keys are project-scoped; unauthorized foreign IDs are denied at the API/backend layer.
- [x] Both fully configured tenant launch forms allow one further VM and disable two further VMs at the configured limit; no form was submitted in this negative check. Provider quota denial evidence is recorded separately in T48.
- [x] Both new tenants' noVNC consoles connected over HTTPS/WSS with 1024×768 framebuffers. Private SSH keys remain root-only and were not uploaded or committed.
- [ ] Provisioning errors expose an allowlisted reason and recovery hint without request secrets, tokens or raw provider traces.
- [ ] API/CLI and browser inventory agree for the same scoped identity.

## Preservation

Use only explicitly marked test resources and approved images/networks. Inspect the pre-existing demo VM before and after; never clean it up as part of this task.
