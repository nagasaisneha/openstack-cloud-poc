## Proposed decision — provisioning identifiers and job tracking (pending requirements-owner approval)

The requirements state that provisioning requests return a job/resource identifier but do not specify which execution outcomes produce each identifier. Proposed interpretation: an accepted-only request returns neither; synchronous completion may return a provider-evidenced resource ID; asynchronous acceptance may return a job ID only after an execution mechanism accepts the work. Fixture identifiers and outcomes remain simulated. T14's standalone tracker does not satisfy integrated POC-017 tracking. This interpretation is not an approved requirements change.
